離散型等比例打獵模型 (Discrete Proportional Harvesting Model)

當每一次的捕獵數量與當前的族群密度成正比，且時間以代／年為離散單位更新。

1. 離散邏輯斯諦差分方程 (Discrete Logistic Difference Equation)

在無外界干擾狀況下，有限資源下的離散族群增長模型為（明年的族群等於今年的族群加上淨成長量）：

\[N_{t+1} = N_t + rN_t \left(1 - \frac{N_t}{K}\right)\]

其中：\(N_t\) 為第 \(t\) 年族群大小，\(r\) 為內在成長率，\(K\) 為環境負荷量。

2. 引入等比例打獵項 (Proportional Harvesting)

若打獵強度為常數 \(h\)，代表每年獵捕當前族群總量的 \(h \times 100\%\)（即捕獵量為 \(hN_t\)）。則系統的差分迭代公式為：

\[N_{t+1} = N_t + rN_t \left(1 - \frac{N_t}{K}\right) - hN_t\]

我們可將其合併同類項重組：

\[N_{t+1} = N_t + (r - h)N_t \left[ 1 - \frac{N_t}{K\!\left(1 - \dfrac{h}{r}\right)} \right]\]

3. 離散時間動態與獨特現象 (Discrete Dynamics & Chaos)

離散模型完全不需要微積分概念，但能展現出連續模型所沒有的動態現象：

  • 平滑接近 (\(r \le 1.0\))： 族群漸近穩定到達新環境負荷量 \(K' = K(1 - h/r)\)。
  • 超越與阻尼震盪 (\(1.0 < r < 2.0\))： 族群繁殖釋放有時間滯後，第一年會衝過頭（超越 \(K'\)），隨後在 \(K'\) 上下展開阻尼震盪並漸近穩定。
  • 週期倍增與混沌 (\(r > 2.57\))： 族群數量會在多個數值間跳躍甚至出現確定性混沌現象 (Chaos)！

臨界結論：

1. 當 \(h < r\) 時，系統存在平衡點 \(N^* = K\!\left(1 - \dfrac{h}{r}\right)\)。

2. 當 \(h \ge r\) 時，捕撈速度超越族群自我復原速度，族群必定走向完全滅絕（Extinction）。

離散型固定數量打獵模型 (Discrete Constant Quota Model)

當每年固定移走特定數量的個體（如每年抓走 Y 隻），以離散世代進行迭代。

1. 離散固定數量打獵差分方程式

如果每年固定獵捕的數量為常數 \(Y\)，則第 \(t+1\) 年族群數量公式為：

\[N_{t+1} = N_t + rN_t\left(1 - \frac{N_t}{K}\right) - Y\]

若要尋找族群不再增減的平衡點（即 \(N_{t+1} = N_t\)）：

\[rN\left(1 - \frac{N}{K}\right) - Y = 0 \quad \implies \quad N^2 - KN + \frac{KY}{r} = 0\]

2. 臨界最大永續產量 (Maximum Sustainable Yield, MSY)

利用一元二次方程式的判別式 \(\Delta = b^2 - 4ac \ge 0\)，方程才有實數解（即存在平衡點）：

\[K^2 - \frac{4KY}{r} \ge 0 \quad \implies \quad Y \le \frac{rK}{4}\]

這說明：在固定量捕獵下，最大的永續捕獲量 (MSY) 是：

\[Y_{\text{MSY}} = \frac{rK}{4}\]

臨界結論：如果您的捕獵設定值 \(Y > \dfrac{rK}{4}\)，系統將不存在任何平衡點。這意味著捕殺速度永遠大於繁殖補給速度，不論起始族群有多大，族群一定會毫無懸念地崩潰並走向滅絕。

3. 鞍節分岔與關鍵崩潰門檻 (Saddle-Node Bifurcation)

當 \(Y < \dfrac{rK}{4}\) 時，公式會解出兩個平衡點：

\[N^* = \frac{K \pm \sqrt{K^2 - \dfrac{4KY}{r}}}{2}\]
  • 穩定平衡點 (Stable Point)： \(N_1^* = \dfrac{K + \sqrt{K^2 - \frac{4KY}{r}}}{2}\)。當起始族群高於門檻時，會逐漸穩定在此新攜帶量。
  • 不穩定平衡點／滅絕門檻 (Unstable Threshold)： \(N_2^* = \dfrac{K - \sqrt{K^2 - \frac{4KY}{r}}}{2}\)。

世紀生態警訊（阿利效應）：

如果起始族群 \(N_0\) 小於 不穩定平衡點 \(N_2^*\)，由於極低密度下的族群年繁殖數量少於固定的採收量 \(Y\)，族群會加速死亡並走向滅絕。這也是為什麼許多遭到過度捕撈的海洋魚類，在捕撈減少後也依然無法恢復的原因之一。

模型定義 (Model Scenario)

採收量不隨族群大小調整

固定數量捕獵機制

人們在單位時間內，固定移走特定數量的個體。

例如：設定每年獵捕數量為常數 \(Y\)，無論此時族群數量剩下多少，每年皆強行移走 \(Y\) 隻個體。捕獵量不隨族群大小調整，容易造成低密度下的滅絕風險。
